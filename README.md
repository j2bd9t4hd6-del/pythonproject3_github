# PythonProject3: Letter-Experience Messaging App Prototype

This is a prototype of a messaging application designed to provide a "real letter" experience. This project is built upon the foundation of pythonproject2_github, inheriting its database management and authentication systems.

Core Concept:
To recreate the tactile and emotional experience of sending/receiving traditional letters in a digital format.
----
Current Status (May 11 2026):

Currently developing the core functions for sending, receiving, and storing messages using SQLite.

Database schema design for message tracking is in progress.
----
